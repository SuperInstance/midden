# The midden, for engineers

Audience: you can read code and you want the real architecture, the
invariants, and the extension points — no poetry, everything checkable.

## What the repo is

A static site plus a protocol file, rendering a dusk scene from five
real fleet fixtures. No server code, no build step, no framework. Two
deliverables:

| Piece | Entry | Constraint |
|---|---|---|
| Dusk scene | `index.html` + `midden.js` | needs static HTTP (browsers gate `fetch`) |
| Walkable world | `world/index.html` | plain `file://` — no modules, no fetch |

## The data layer (`data/`, 6 fixtures)

Every file is either REAL fleet output captured at authoring time or
explicitly labeled SYNTHETIC — the doctrine is written down and enforced
in `data/PROVENANCE.md`. The honest-ledger law lives in
`test/fixtures.test.mjs`: every ledger ridge must carry transcript
evidence (`source`, `ref`, `quote`), strengths in (0,1], refs inside
the real turn count. Zero-invention is a test, not a hope.

| Fixture | Source | Contents |
|---|---|---|
| `terrain.json` | real `extractValuesLedger` (the-tap @ `42f878e`) over the commune harness | 9 value ridges + evidence |
| `lineage.json` | real `breed()/chain()` ℚ¹⁶ walk | seed, artist, 8×16 matrix |
| `whirlpools.json` | 4 real OPEN canon-gap issues | edges + URLs + state |
| `sky.json` | the canon hash | `0x445185a3a99fd2e7`, 16 digits |
| `choir.json` | the commensuration comb | 7 teeth, exact rational degrees |
| `candor-run.json` | candor v0 first real run (candor @ `e4a85f30`) | twist-instrument verdicts; 2/3 corpora labeled SYNTHETIC |

## The protocol layer (`protocol/`)

`midden-room.json` is a **self-describing room state**: it pins the
fixtures (sha256 + byte sizes), declares instruments with units
(`torsion` — dimensionless; `twist-shear` — seconds, never
dimensionless), and carries surfaces that must *trace* the fixtures
point-for-point. `room-state.schema.json` validates it, and the test
suite proves the validator rejects a deliberately broken room (≥4
distinct violations). The strain line is labeled `stand-in` with a
matching prose note — derived estimates never wear the uniform of
measurements.

## The render layer

`midden.js` draws the scene straight onto canvas from the fixtures —
no scene graph, no deps. The walkable world in `world/` lays cells out
by a **deterministic PCA of the real 8×16 matrix at uniform scale**, so
the floor keeps the walk's own shape; trails are the real ancestry
edges. SYNTHETIC rooms are generated by damped least-squares
extrapolation (decay 0.85/step, clamped to the walk's ℚ-range), carry
`provenance.syntheticMethod`, wear broken rings, and get no verdict
tag.

## Invariants worth respecting

1. **Real-or-labeled, no third option.** Every fixture cites repo+ref;
   every synthetic room is marked twice (JSON + rendering).
2. **Pins must trace.** Changing a fixture without re-pinning
   `midden-room.json` fails `tests/room-protocol.test.js` (hashes,
   byte sizes, surface equality). PR #4 hit exactly this; the repin
   tool is `tools/repin-after-pr4.mjs`.
3. **The naming law.** Third-order readout = TORSION. The schema
   forbids a `twist` key in readout rows (`additionalProperties: false`),
   and no test may introduce one.
4. **Honesty of estimation.** `status: "stand-in"` on derived lines;
   instruments carry units; SYNTHETIC glows dim.

## Verify

```bash
node --test        # 60 tests, expected 60/60 green
```

`test/smoke.mjs` recomputes the world's room readouts live from
`data/lineage.json` — the no-drift guard. CI should run plain
`node --test` (the `package.json` script).

## Extending it

- New real artifact → add fixture + PROVENANCE.md section + repin
  (hashes, sources) + surface that traces it + test that fails when
  they drift.
- New instrument → declare in `room.instruments` with units; if it's an
  estimate, label it stand-in and say what it's derived from.
- New rendering → must not let SYNTHETIC cells glow like REAL ones.
